# Lora HUD font

Unmodified variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/lora), source `Lora[wght].ttf`. Copyright 2011 The Lora Project Authors. Licensed under SIL Open Font License1.1; see OFL.txt.

Only HUD display/card text uses this font. ui/hud/display_font.tres selects weight600 without modifying the font. World sprites and other game typography retain their existing rendering.
