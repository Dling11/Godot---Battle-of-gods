# Minimal art support

Decision223, owner-authorized2026-10-16. Finished game-ready artwork/frames/resources under assets/ are authoritative. The bulky generated directory and dependent image builders are deleted.

Keep only production-assets.json (accepted installed resource hashes), reference/characters/king (small approved identity images plus axe-motion.json and reaper-grounding.json numeric regression data), and audio/ (licensed originals and attribution for maintained sound tools). These support consistency/verification without retaining all generations.

Future raw generations/trials belong in ignored tmp/ while working. Publish approved runtime assets, validate them, then clear staging. Do not recreate a permanent generated/archive collection. Update accepted hashes only for an explicitly approved change.
